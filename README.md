Organización del repositorio
El repositorio se administra según el Plan de Gestión de Configuración del grupo, ubicado en SCM/. Allí se definen los ítems de configuración, las reglas de nombrado, el versionado y los criterios para crear líneas base.

Carpeta	Contenido
Documentacion_Academica/	Programa, cronograma y presentación de la cátedra. La subcarpeta Material_Apoyo/ contiene documentación complementaria (por ejemplo, sobre parciales).
Material_Teorico/	Presentaciones/ de clase y Bibliografia/, organizada en una subcarpeta por tema.
Material_Practico/	Guias/, Templates/ y Lineamientos/ provistos por la cátedra.
Entregas_Grupales/	Entregables del grupo: Trabajos_Practicos/TP_[NN]/ y Trabajos_Investigacion/TI_[NN]/.
SCM/	Plan de Gestión de Configuración del grupo.
Convenciones principales
Los nombres de archivo de los ítems de configuración van en minúscula, sin tildes ni caracteres especiales, con _ como separador.
Todo ítem de configuración lleva versión con formato v[mayor].[menor] e ingresa como v1.0.
Ejemplo de entregable: tp_04_4k2_g10_scm_informe_v1.0.pdf.
Las líneas base se marcan con tags anotados de Git con el formato lb_[NN]_[HITO] (por ejemplo, lb_01_tp06_finalizado).
Las reglas completas están en el Plan de Gestión de Configuración.

README.md, .gitignore y los archivos .gitkeep son archivos de soporte del repositorio y no se consideran ítems de configuración.
